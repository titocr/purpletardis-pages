# purpletardis-pages

Static landing page for `purpletardis.xyz`.

This repository hosts the public front door for the Purpletardis media setup.

This repo is public, so keep it free of secrets, credentials, private IPs, and runtime-only config.

The first version is intentionally small:
- clear brand
- one primary action
- simple links to the services that will be exposed later
- easy deployment with `git push`
